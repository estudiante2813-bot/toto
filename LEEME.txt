TU REGALO PARA VALE ❤️

1. Abrí index.html para probar la página en tu computadora. Las fotos deben permanecer dentro de la carpeta fotos.
2. Para publicarla gratis y tener un enlace para compartir, subí todo el contenido de esta carpeta (index.html y la carpeta fotos) a un servicio de hosting estático como Netlify Drop: https://app.netlify.com/drop
3. También podés usar GitHub Pages o Cloudflare Pages. No subas solo el index.html: incluí la carpeta fotos.

La música usa el reproductor de YouTube y puede necesitar que la persona toque reproducir, especialmente en celulares.
